# TJ & U Auto Garage – booking store demo

A demo of the TJ & U Auto Garage (Rabai Road, Buruburu) WooCommerce booking store that runs entirely in the browser with WordPress Playground.

- Booking site: https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/salvatorewanjohi-a11y/tj-and-u-auto-demo/main/blueprint.json
- Store admin (services, prices, bookings): https://playground.wordpress.net/?mode=seamless&blueprint-url=https://raw.githubusercontent.com/salvatorewanjohi-a11y/tj-and-u-auto-demo/main/blueprint-admin.json

Each visit builds a fresh copy, so test bookings are not kept.
